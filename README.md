# Digital Ustaad

Interactive, accessible smartphone practice for Pakistani parents and grandparents — built by **Team TUBS** for Build4Better 2026.

## Phase 1 (current)

- React + Vite + Tailwind CSS foundation
- Global design system and application shell
- Welcome / onboarding screen
- Learning dashboard with flagship lesson: **Learn to share a family photo**
- LocalStorage for view preference and lesson interest
- Navigation between welcome and dashboard

Guided phone simulation, practice modes, and results screens are planned for later phases.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Stack

- React (JavaScript)
- Vite
- Tailwind CSS
- Lucide React
- Framer Motion
- LocalStorage
